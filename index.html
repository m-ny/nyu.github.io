NYU Organization on GitHub

github.com/nyu is a GitHub organization for projects developed by students, staff, and faculty at New York University. You can automatically join the organization by visiting this URL: Click to Join

There are only a few guidelines we maintain within this organization:

  • Projects must be original, open source work. (Use your own personal GitHub for forks, open course projects, etc.)
  • Projects must contain a README file. (Don't dump random code in @nyu.)
  • This work should be something you are proud to associate with yourself and NYU. If you're not sure, it is best to host it on your own GitHub account.

That's it! Feel free to use any open-source license that fits your needs, though we encourage responsible licensing practices.

Projects hosted on github.com/nyu are not officially endorsed by New York University.

Happy coding!
